О проекте

Этот проект создан для практических упражнений по автоматизации тестирования. Сервис и автотесты к нему написаны с нуля и устроены «как на работе»: отдельные репозитории, несколько стендов, CI, внешняя интеграция, асинхронный обмен сообщениями и контроль контракта API. На нём я отрабатываю подходы, которые затем переношу в рабочие проекты и в обучение коллег.

Что есть сейчас

Сервис Task Lab

  • REST API и веб-страницы: задачи, поиск, роли USER и ADMIN
  • PostgreSQL и миграции Flyway
  • Kafka: события об изменениях, команды, очередь отклонённых сообщений
  • Вход по JWT для API и по форме для страниц
  • Проверка исполнителя во внешнем справочнике по OAuth2

Автотесты

  • Java 21, JUnit 5, REST Assured, Selenide, Allure, Spring
  • API, база данных, Kafka и UI (Page Object)
  • Контракт ответов и событий по JSON Schema
  • Заглушка внешней системы на WireMock
  • Фикстуры-аннотации, параллельный запуск

Инфраструктура

  • Стенды dev и stage в Docker
  • Jenkins: деплой, smoke при изменениях, ночной регресс, отчёты Allure, сводка в Telegram
  • Этот сайт: стенд prod на VPS, HTTPS (Caddy, Let's Encrypt), деплой и откат по SSH
