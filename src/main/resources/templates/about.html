О проекте

Учебное приложение для практики автоматизированного тестирования.

В Task Lab можно создавать, искать, изменять и удалять задачи. Приложение намеренно простое: на нём удобно отрабатывать тесты, не отвлекаясь на сложную логику.

  • UI-тесты: у ключевых элементов есть атрибуты data-testid.
  • API-тесты: те же операции доступны через REST.
  • Данные: задачи хранятся в базе данных.

Планируется: авторизация, роли пользователей и расширенные фильтры.
